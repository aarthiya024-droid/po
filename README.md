# PocketSmart AI

## Your Smart Budget & Recommendation Assistant

PocketSmart AI is a Generative AI based budget and recommendation assistant.

The application allows users to:

- Record expenses
- Categorize expenses
- View spending totals
- View spending by category
- Parse natural language expenses
- Generate AI spending insights
- Generate budget-based recommendations
- Store AI interaction history
